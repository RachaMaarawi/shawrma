# 🌯 SHAWRMA RUN: LAST ORDER

An arcade-style, web-based 2D mobile endless-runner game built using JavaScript and **Phaser 3**, featuring vibrant graphics and fast-paced action.

## 🕹️ About The Project
**SHAWRMA RUN: LAST ORDER** is a lightweight browser game where players navigate obstacles and collect items in a dynamic, high-speed setting. Built with modular JavaScript architecture, it runs directly in the browser with no installation required.

## 🚀 Features
- **Smooth 2D Physics & Mechanics:** Powered by the Phaser 3 framework for responsive controls and fluid gameplay.
- **Arcade Endless Runner Style:** Progressive difficulty and obstacle-dodging action.
- **Cross-Platform / Mobile-Friendly:** Designed to perform seamlessly across modern desktop and mobile browsers.
